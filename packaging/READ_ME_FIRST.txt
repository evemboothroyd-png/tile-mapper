TILE MAPPER — INSTALLING

1. Drag "Tile Mapper" onto the Applications folder in this window.

2. The first time only: open your Applications folder and double-click Tile Mapper.
   macOS will say it can't check the app. Click "Done" (or "Cancel"), then open
   System Settings ▸ Privacy & Security, scroll down, and click "Open Anyway"
   next to Tile Mapper. Confirm once more. After that it opens normally.
   (This happens because the app isn't registered with Apple. It's safe.)

3. When it starts, choose the folder that holds your map tiles.

PRINTING TO SCALE
Use File ▸ Print / Export… ▸ "Full size — split into printer pages".
When printing the PDF, set Scale to 100% (not "Fit to page"). Each page has a
1-inch square in the corner you can measure to check.
