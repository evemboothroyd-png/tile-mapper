**New in 0.1.2 and 0.1.3:** the "Float on top" box is gone. Every tile overlaps freely, and dropping a tile on another no longer replaces it. New toolbar buttons control which tile is on top: **To Top**, **Up One**, **Down One**, and **To Bottom** (also in the Tile menu, with ⌘⇧], ⌘], ⌘[, and ⌘⇧[). White background around the edge of every tile is now see-through, so whatever is underneath shows; white inside the artwork stays white.

**Which file do I need?** Apple menu ▸ About This Mac.
- *Chip: Apple M1/M2/M3/M4…* → download the file ending in **arm64.dmg**
- *Processor: Intel…* → download the file ending in **x86_64.dmg**

**Installing:** open the DMG and drag Tile Mapper to Applications. The first time, macOS will block it because it isn't registered with Apple: open **System Settings ▸ Privacy & Security**, scroll down, and click **Open Anyway** next to Tile Mapper. After that it opens normally. Full steps are in READ_ME_FIRST.txt inside the DMG.

**Printing to scale:** File ▸ Print / Export… ▸ *Full size — split into printer pages*, then print the PDF at **Scale 100%** (not "Fit to page"). Measure the 1-inch square on any page to check.
